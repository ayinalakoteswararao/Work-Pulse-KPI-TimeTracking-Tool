# KPI Time Tracking Tool Workflow

## 1. Dashboard Overview
// turbo
- Navigate to Dashboard to see:
  - Total employees, departments, roles, and KPIs
  - Today's and week's work entries
  - Top performers and underperformers

## 2. Manage Timesheets
// turbo
- Go to "Time Sheet" menu
- For employees: Log work sessions and task entries
- For managers/admins:
  - View work summaries with filters (Company, Dept, Role, Employee)
  - Toggle between Employee-wise and Date-wise views
  - Export data to CSV

## 3. KPI Dashboard
// turbo
- Navigate to "Performance" → "KPI Dashboard"
- Filter by period (Today, Week, Month, Last Month)
- View performance summaries with department/role filters
- Export KPI data to Excel
- Create new KPIs (admin only)

## 4. Workload Report
// turbo
- Go to "Work Load" menu
- Filter logs by Company, Department, Role, Employee, Project, Module
- Export Excel report
- Generate Performance Slip PDF
- View task statistics and performance charts

## 5. Employee Management
// turbo
- Access "Config" → "Employees" to:
  - Add new employees
  - Edit employee details
  - Assign roles and departments

## 6. Admin Configuration
// turbo
- Navigate to "Config" menu for:
  - Companies management
  - Departments setup
  - Roles configuration
  - Function targets
  - KPI definitions

## Export Data Format

All exports follow standard CSV format with headers:
- Employee Name, Date, Status, Summary, Hours, Created At

## Filter Dependencies
- Company selection affects Department list
- Department selection affects Employee list
- Role selection filters relevant functions
